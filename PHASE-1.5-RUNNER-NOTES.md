# SHORE DASH — Phase 1.5 / 1.5.5

## Product direction
Swipe-first, single-path mobile runner. The player has free horizontal positioning inside a continuously moving beach/surf corridor rather than fixed three-lane switching.

## Phase 1.5 goals
- Keep the canvas as the mobile control surface.
- Tap/swipe-up jump, horizontal swipe dodge, swipe-down slide.
- Preserve keyboard controls for PC.
- Remove visible mobile joystick/button clutter.
- Keep responsive portrait/landscape layout and screen-space HUD.

## Phase 1.5.5 goals
- Dynamic single-lane path bounds.
- Smooth horizontal positioning with path clamping.
- Obstacles and collectibles spawn inside the active path.
- Path width/center changes over time to create repositioning decisions.
- Add slide state and lower hitbox.
- Prepare the architecture for later wave sections, dash, power-ups, and environmental events.

## Next phase
Phase 2 will add dash, shields, wave events, richer obstacle combinations, power-ups, and difficulty progression after this architecture is play-tested.
